# Service: Tax Preparation

Slug: `tax-preparation` · Pages: `/services/tax-preparation`, `/services/tax-preparation/{united-states,united-kingdom,australia}`

## What it is

Return preparation support: organized workpapers, source-document handling, return preparation, review notes, and a clear handoff to the licensed professional responsible for the final return.

## Deliverables (can be delegated)

- Organizing source documents and workpapers
- Return preparation (draft returns for review)
- Quarterly estimated tax calculations
- BAS-ready GST records (Australia)
- Multi-state return preparation (US)

## Stays with the client / CPA / EA / registered agent

- **US:** Final review, sign-off, e-filing, and any IRS contact — licensed CPA or Enrolled Agent only. **Never claim IRS representation or power of attorney** (Circular 230). See `knowledge/company/scope-boundaries.md` §2 — this is the single highest-risk boundary on the site.
- **UK:** HMRC submission — the registered practitioner. Accounstone must not hold HMRC portal credentials.
- **AU:** Lodgment — registered tax agent. BAS lodgment — registered BAS agent. Accounstone must not hold ATO portal access.
- Tax planning, tax strategy, tax optimization, entity selection advice — none of this is offered at any stage. Return preparation only.
